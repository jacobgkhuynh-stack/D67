# Diodeless-Keyboard with 67 keys in a 65% layout
So here's what this is, a Diodeless Keyboard that uses graph theory like Triliu's JESK56 keyboard https://github.com/triliu/JESK56 but using a different graph https://houseofgraphs.org/graphs/49999.
The nodes are pins and the vertices of the graph are switches using this method and placing them in a way can make it so that practically when using the board it feels like a n-key-rollover board even though it' actually only 4-key-rollover
I made this for week 5 of Hack Club's Halflife program.
I have no clue if it works but it took a ton of time.
Oh yeah, you can replace the 2 keys near the bottom right with a oled display if you wanted
